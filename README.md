# 飞行棋 · OTools 插件（otools-feixingqi）

2-4 人本机飞行棋：掷 6 起飞、同色格连跳、虚线飞线捷径、撞机返回机库；自带
**海洋 / 热带雨林 / 沙漠** 三大主题背景故事与全套主题化事件文案。纯静态实现
（原生 HTML/CSS/JS ES modules），无 npm、无框架、无打包器。

## 玩法与规则

- **座位**：红 / 黄 / 蓝 / 绿四色座位（主题里可改称谓，如「珊瑚队」），可开关任意
  座位，每座可为本地玩家或电脑（简单 / 普通 / 困难三档 AI），至少 2 座参战。
- **起飞**：掷出 **6 点** 才能把飞机从机库送上起飞格；掷 6 行动后奖励再掷一次
  （一回合内奖励掷骰上限 3 次，防极端循环）。
- **同色连跳**：落在己方颜色格，免费跳到下一个己方颜色格（+4）；若跳到的恰是
  飞线入口，则改为飞线、不再跳。
- **飞线捷径**：每色固定 3 个入口格（棋盘上虚线框标记）。**掷骰直接踏上**入口：
  沿虚线飞越 **+12** 格，落地后再跳 +4；由连跳**跳到**入口：只飞越 +12。
  飞行途中越过的「十字交叉格」（入口 +6 处）若有敌方棋子，一并撞回机场。
- **撞机**：任何落点（含起飞落点、连跳 / 飞线后的落点）若有敌方棋子，该格敌方
  棋子全部返回机库；路过与跳过不撞。
- **叠子（所选规则变体）**：落到己方棋子所在格可叠子（同格 ≤4 架）。叠子**没有**
  防护能力：被对方撞机时**全体返回**机库（标准实体棋常见口径之一，数字实现常用
  此简化，本插件明确采用并在事件日志中给出叠子提示）。
- **终点引道**：越过己方跑道入口格后转入 6 格引道，必须**整点**进入终点，
  超出步数反弹回走；引道内不受撞机影响。
- **胜负**：率先让 4 架飞机全部到达机场者获胜；第一名完成即结算，其余座位按
  （到达数，总里程）排名。
- **无法行动**：全部飞机在机库且未掷出 6 时自动过。

> 掷 6 起飞、起飞格不触发连跳/飞线、飞线「踏上跳到」区别、交叉格撞机等细节
> 采用维基百科「飞行棋」条目的标准中国飞行棋口径；飞线入口取每色个人步数
> 12/24/36 三格，交叉格取入口 +6。规则数值全部集中在
> `web/js/engine/ludo.js` 顶部常量，与主题、UI 完全解耦。

## 目录结构

```
otools-feixingqi/
├── plugin.json            # 插件清单（devUrl 6545）
├── logo.svg               # 自绘飞行棋主题图标
├── web/                   # 源码（构建时整体拷贝到 dist/）
│   ├── index.html         # 入口：OTools 宿主桥（window.otoolsPlugin）+ 三屏骨架
│   ├── css/style.css      # 深色主题 + 响应式（棋盘 SVG viewBox 随窗口缩放）
│   ├── data/themes.js     # 三主题数据（故事 / 配色 / 棋子 / 事件文案）
│   └── js/
│       ├── engine/ludo.js     # 规则引擎（纯函数、无 DOM、随机源可注入）
│       ├── engine/ludo-ai.js  # AI（纯函数评分制：easy / normal / hard）
│       ├── engine/rng.js      # 可注入、可存档的 mulberry32 随机源
│       └── ui/                # app.js 编排 / board.js 棋盘 / log.js 日志
├── tests/                 # node --test 测试（规则 / AI / 主题），种子随机
└── scripts/               # 模板脚本（未改动）：build-web / serve-dist / pack…
```

## 开发

```bash
node --test tests/            # 全部测试（引擎规则 / AI / 主题数据完整性）
node scripts/build-web.mjs    # web/ → dist/（唯一构建入口，无依赖）
node scripts/serve-dist.mjs   # 本地预览 dist/
```

- 规则引擎与 AI 均为纯函数、无 DOM，`node --test` 直接 import；随机源经
  `createGame({rng})` / `rollDice(state, rng)` 注入（`engine/rng.js` 的
  mulberry32，状态可序列化），种子可复现任意整局。
- 引擎状态为纯 JSON（座位配置 / 各机个人步数 / 骰点 / 连跳飞行链 / 日志），
  `serializeState` / `hydrateState` 支持存档恢复；UI 每 步自动存
  localStorage，重进可「继续对局」。
- OTools 宿主内可通过宿主桥（`window.otoolsPlugin.saveText`）把对局记录导出
  为 JSON；浏览器直开时退回 Blob 下载。
- 移动端：棋盘 SVG 随窗口缩放，窄屏自动上下布局。

## 已知规则变体说明

- **叠子被撞全体返回**：本插件采用的变体（部分实现里叠子可格挡落子，此处不做）。
- **起飞不触发连跳 / 飞线**：起飞只落到起飞格（该格虽为己色，但出闸不借风，
  与常见数字实现一致）。
- **飞线入口与交叉格**取固定抽象位（个人步数 12/24/36；交叉格 = 入口 +6），
  与实体棋盘的虚线布线在几何上等价（飞线折线在棋盘上按此绘制）。
